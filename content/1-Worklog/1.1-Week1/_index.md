## Week 1 objectives:

- Learn how to create an AWS account and apply basic account protection.
- Become familiar with AWS Management Console and the main groups of AWS services.

## Activities completed:

| Date | Activity | Reference |
|---|---|---|
| 08/08/2026 | Review AWS account registration and the initial setup steps before using cloud services. | [AWS Cloud Journey](https://cloudjourney.awsstudygroup.com/) |
| 10/08/2026 | Study account security basics, including strong passwords, multi-factor authentication (MFA), and safe Console access. | [AWS IAM](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html) |
| 12/08/2026 | Explore AWS Management Console, locate common services, and understand Region selection. | [AWS Getting Started](https://aws.amazon.com/getting-started/) |
| 14/08/2026 | Group introductory services into compute, storage, databases, networking, and security. | [AWS Cloud Journey](https://cloudjourney.awsstudygroup.com/) |

## Week 1 outcomes:

- Understand the steps for creating and protecting an AWS account.
- Navigate AWS Management Console and find the services needed for later exercises.
- Recognize the purpose of key AWS service categories as a foundation for upcoming sessions.
