## Personal reflection

### Knowledge and skills improved

I developed knowledge of AWS services, particularly Lambda, API Gateway, DynamoDB and components supporting authentication and monitoring. Through NetMon, I learned how to break device management requirements into API operations, identify data to store and coordinate UI integration checks. I also gained a better understanding of reviewing logs to isolate issues instead of changing multiple settings at once.

### Strengths

- Take assigned responsibilities seriously and follow internship rules.
- Proactively look for documentation and explore possible solutions when errors occur.
- Coordinate with teammates to agree on data structures and integrate system components.

### Areas for improvement

- I do not learn certain unfamiliar topics as quickly as I would like; I need more time to read documentation and repeat exercises before fully understanding them.
- My communication and technical presentation skills need improvement, particularly when explaining complex issues concisely.
- My technical knowledge needs further development, especially IAM permissions, automated testing and cost optimization in real deployments.

## Development goals after the internship

I plan to continue studying AWS serverless services topic by topic, combining practice with notes on the results to improve my independent learning skills. In teamwork, I want to practice explaining problems through their symptoms, possible causes, evidence and proposed solutions. This can make discussions clearer and reduce misunderstandings.

Technically, I aim to strengthen API programming, database design, application security and system monitoring. I also want to explore infrastructure as code and methods for collecting metrics from physical network devices. The internship is a starting point for identifying the knowledge and skills I need to develop next.
