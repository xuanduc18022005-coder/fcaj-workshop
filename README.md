# Báo cáo thực tập AWS FCJ

Website báo cáo thực tập của Trần Xuân Đức, sử dụng Hugo, hỗ trợ tiếng Việt và tiếng Anh.

## Chạy trên máy tính

Mở thư mục chứa `config.toml` trong VS Code và chạy `hugo server`.

- Tiếng Việt: http://localhost:1313/vi/
- English: http://localhost:1313/en/

Nội dung nằm trong `content/`, ảnh trong `static/images/`, giao diện trong `layouts/`. Hugo tự tạo `public/`.

## GitHub Pages

Đưa mã nguồn lên repository và chọn Settings → Pages → Source → GitHub Actions. Workflow đã nằm trong `.github/workflows/`. Kiểm tra thông tin cá nhân và ảnh Console trước khi công khai.
